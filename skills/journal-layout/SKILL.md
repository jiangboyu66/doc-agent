# 学术期刊排版规范与工作流

## 一、版面规则（期刊排版的共识，LaTeX 期刊模板的默认行为）
1. 浮动体（图、表）
   - 宽于一栏的图表占满整行（跨两栏、居中），放在页面**顶部**；不放在第一页（标题、摘要在上）；
   - 栏宽的图表：当前栏剩余空间放得下就紧跟在引用它的段落之后，放不下就移到**下一栏顶部**，文字继续排满当前栏；
   - 图表出现在第一次引用它的位置之后（同页顶部也可以），先后顺序与编号一致；
   - 表题在表上方（TABLE I / 表 1），图题在图下方（Fig. 1 / 图 1）。
2. 不被打断
   - 表格每一行不跨页；整张表与表题在同一页；图与图题不分离；
   - 只有比一整页还长的表格才允许跨页（这时应提醒用户考虑拆表或缩小字号）。
3. 页面饱满、栏底平齐
   - 除最后一页外，每页正文区排满，不出现大块空白；
   - 两栏的每一行在同一高度（基线网格）：段前段后距、标题、公式、栏内图表的高度都是正文行距的整数倍；
   - 关闭孤行控制（它会让某一栏少一行）；标题与下一段保持在同一栏（宁可栏底空一两行，也不让标题孤零零落在栏底）。

## 二、工作流
1. `doc_outline` 了解结构，确认是双栏论文、图表都有题注。
   - 若文档由 PDF 以「逐页保留原排版」方式转换（每行硬换行），先 `doc_convert_to_word(layout="flow")` 转换为可编辑排版。
   - 题注必须以 `Fig. 1:` / `Figure 1.` / `TABLE I` / `图 1` / `表 1` 开头才能识别；格式不规范的题注先用 doc_replace_text 修正编号写法（只改编号前缀，不改题注内容）。
2. 调用 `doc_journal_layout`（默认参数即可）。它会：
   - 识别全部带题注的图表，宽图表改为通栏单栏节，设置不跨页 / 与题注同页；
   - 统一正文固定行距、关闭孤行控制、把各种间距凑成行距整数倍；
   - 用 LibreOffice 实际分页，逐个把图表放到合适的位置：段落恰好在页顶 / 栏顶被分开时，会把段落拆成两段（前半段末行两端对齐，后半段不缩进），视觉上与连续的段落一致；
   - 再渲染一次检查，报告仍有留白、两栏未对齐的页。
3. 把报告用一两句话告诉用户：放到页顶的通栏图表、移动到下一栏的图表、仍有问题的页面及原因。
4. 仍有大面积留白时（通常是某张图表太大，哪里都放不下），向用户提出可选方案，不要擅自改内容：缩小该图的宽度、把大表拆成两张、把表格字号减小 0.5–1 pt。
5. 之后用户再修改内容（扩写、增删段落、插入图表），**修改完成后再运行一次 `doc_journal_layout`**：它会先还原上一次的排版（合并拆开的段落、图表回到引用位置），再重新排。
6. 需要交付 PDF 时用 `doc_export(format="pdf")`，与排版时使用的是同一个渲染引擎，版面一致。

## 三、注意
- 本工具只改版面：段距、行距、分节、图表位置与对齐，不改任何文字、字体、字号、题注内容。
- 修订模式下排版调整不会记录为逐条修订（它是全局版面操作）；需要审阅时先关闭修订模式再排版，并告知用户。
- 第一页的标题、作者、摘要区域保持原样；图表不会放到第一页。
- 用户只想让某一张图表保持原位时，用 `floats="none"` 运行（只做不跨页与网格对齐），再手动 `doc_move_blocks` 调整那一张。
