# 格式一致性工作流

## 原则
统一格式 = 让同类段落使用同一个样式，并去掉与样式冲突的直接格式。优先"套用样式"，而不是给每段手动设置字号字体——这样与模板保持一致，用户以后改样式也能全局生效。

## 步骤
1. doc_styles：了解文档中在用的样式及使用次数。使用次数最多的正文样式通常就是"标准正文样式"。
2. doc_outline：检查标题层级是否连续（1 级下直接跳 3 级？）、同级标题是否用了不同样式。
3. 抽样 doc_inspect：选一个"正确"的正文段落和一个"看起来不对"的段落对比，找出差异（字号、字体、缩进、间距、是否有直接格式）。
4. 列出问题清单（todo_write），向用户说明准备怎么统一，得到同意后再改：
   - 样式用错：doc_set_paragraph 设置正确的 style；
   - 段落直接格式异常（缩进、间距、对齐）：doc_set_paragraph 修正为与标准段落一致的值；
   - 文字直接格式异常（个别句子字号/字体不同）：doc_format_text 修正为标准值。
5. 批量修改时一次调用处理多个段落引用（doc_set_paragraph 的 refs 支持数组）。
6. 完成后 doc_verify；如文档较长，启动 verifier 抽查。

## 注意
- 不要改变有意为之的格式：强调用的加粗/斜体、上下标、公式、代码、表格内的特殊对齐。
- 期刊模板（如 IEEE）有专用样式，先加载对应技能了解样式含义。
