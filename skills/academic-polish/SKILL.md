# 学术润色规范

## 底线（任何情况下都不能违反）
- 不改变事实、数据、结论、实验条件、引用编号 [n]、公式编号 (n)、图表编号。
- 不增加原文没有的论断；不删除限定词（may、approximately、在一定程度上……）。
- 专有名词、术语、缩写保持原样；全文同一概念用同一个术语。
- 只润色用户指定的范围；未指定时先询问范围，不要默认润色全文。

## 润色要点
英文：主谓一致、时态统一（方法与结果用过去时，普遍结论用现在时）、冠词、介词搭配、冗余表达（in order to → to；it is worth noting that → 删去）、被动语态过多时适度改为主动、长句拆分、连接词衔接。
中文：去口语化（"我们发现"→"结果表明"视语境而定）、消除歧义与冗长的"的"字结构、统一数字与单位写法、标点规范（中文语境用全角标点）。

## 操作方法
1. doc_read 读取目标段落，逐句判断是否需要修改；不需要修改的句子保持原样。
2. 对每一处修改调用 doc_replace_text：ref 指定段落，old_text 为需要修改的那一句或半句（不要整段替换），new_text 为润色后的版本。系统会只写入真正变化的词，其余字符与格式保持原样。
3. 同一段内多处修改分多次调用，或在一次调用中覆盖连续的一句话。
4. 每改完一个章节，向用户简要说明修改类型（不要复述全文），并提示可在修订模式下逐条审阅。
