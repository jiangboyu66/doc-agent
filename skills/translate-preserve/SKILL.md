# 保留格式的翻译

## 做法
翻译不是新建文档，而是在原文档上逐段替换文字：每个段落的样式、段内加粗/斜体/上标、图片、公式、脚注引用都留在原位。

1. doc_outline 确认范围与段落数；段落多时用 todo_write 按章节建清单，并提醒用户这会产生较多修改（建议 /mode acceptEdits 或开启修订模式后批量确认）。
2. 按章节 doc_read，逐段翻译：
   - 调用 doc_replace_text，ref=段落引用，old_text=该段完整原文（从读取结果复制），new_text=译文；
   - 段内的 ⟨图片⟩⟨公式⟩⟨脚注N⟩⟨符号X⟩ 必须原样出现在译文的对应位置；
   - 段内格式不同的部分（如加粗的术语），译文中对应术语尽量保持在相同位置，系统会按最小差异保留格式；
   - 超长段落可以按句拆成多次替换。
3. 不翻译：参考文献条目、代码、公式、专有名词缩写、URL、人名（除非用户要求）。
4. 术语表：翻译开始前先确定关键术语的译法并在全文统一；可以先向用户确认术语表。
5. 每完成一个章节更新清单；全部完成后 doc_verify。
