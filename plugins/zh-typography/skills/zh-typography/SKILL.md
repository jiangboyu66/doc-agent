# 中文排版规范

1. 中文与英文、中文与阿拉伯数字之间加一个半角空格：「使用 DeepSeek 模型」「共 3 个章节」。
2. 数字与单位之间加空格：「10 Gbps」「5 cm」；度数、百分比例外：「90°」「15%」。
3. 全角标点与其它字符之间不加空格：「这是结论，请注意。」
4. 中文语境使用全角标点（，。；：？！“”（））；英文句子、代码、数字内部使用半角。
5. 不重复使用标点表示强调：不写「！！」「？？」。
6. 专有名词使用正确大小写：GitHub、iPhone、DeepSeek、Word。
7. 省略号用「……」，破折号用「——」。

修改方法：用 doc_search 的 regex 找出问题（例如 `[一-龥][A-Za-z0-9]` 查找缺少空格的中英相邻处），列清单经用户确认后，用 doc_replace_text 逐处修正（带 ref，old_text 取包含问题的最短唯一片段）。
